## Sobre

Pátio de treino + cidade gótica em construção. Combate com combos, esquiva perfeita em câmera lenta, ranking de estilo D–S e 5 armas com skills Q/E/R.

## Controles

`WASD` mover · `Espaço` pular · `Shift` esquivar · Mouse ataques · `Q/E/R` skills · `1/2` armas · `Tab` máscara · `F` interagir · `Esc` pausa
